## Descripción del Proyecto
Este proyecto contiene la resolución de los ejercicios prácticos de POO utilizando Java e IntelliJ IDEA:
* **Ejercicio 1:** Encapsulamiento y constructores de copia en `ejercicio_1`.
* **Ejercicio 2:** Relaciones de asociación, agregación y composición utilizando colecciones (`List`) en `ejercicio_2`.
* **Ejercicio 3:** Implementación de herencia, clases abstractas y polimorfismo en `ejercicio_3`.
* **Ejercicio 4:** Diagrama y mapa de memoria (Stack y Heap) de la ejecución del programa.
